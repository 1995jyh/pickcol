# PRD — 픽콜(가칭) MVP

## 1. MVP 목표 5줄 요약

| 구분 | 내용 |
|------|------|
| **대상** | 대결(이상형 월드컵 스타일) 콘텐츠를 즐기는 일반 사용자. 비로그인 참여 가능. |
| **핵심 루프** | 메인(매치업 목록) → 매치업 페이지(투표 + 게시물 목록/작성) → 게시물 상세(댓글) → 재방문·공유 |
| **가치** | 짧은 시간에 투표·게시물·댓글로 참여감을 주고, SEO 유입용 페이지를 최소 단위로 확보. |
| **수익** | MVP 단계에서는 수익화 미적용. AdSense 등은 Next 단계에서 도입. |
| **제약** | 2~3주 내 구현 가능 범위로 한정. 회원가입·관리자 대시보드는 Next. |

---

## 2. 결정사항(DECISIONS)

| 항목 | 결정 내용 |
|------|------------|
| **익명 식별** | `anon_id`(UUID)를 클라이언트에서 1회 생성 후 **localStorage + cookie**에 저장. 투표/게시물/댓글/신고 시 동일 값으로 식별. |
| **투표** | 매치업당 **anon_id 1회만** 투표 가능. 제출 후 **변경 불가**. DB unique(anon_id, matchup_id) 등으로 보장. |
| **게시물** | 매치업 페이지에서 게시물 작성 가능(제목+본문+닉네임 선택). 동일 anon_id 기준 **작성 쿨다운(예: 30초)**. |
| **게시물 댓글** | 게시물 상세에서 댓글 작성/열람. 본문 **5~500자**, 동일 anon_id 기준 **10초 쿨다운**. |
| **매치업 댓글** | MVP에서는 사용하지 않음(Next). 토론은 “게시물/게시물 댓글” 중심으로 진행. |
| **신고 사유** | **SPAM / HATE / NSFW / ILLEGAL / OTHER** 5종만 허용. |
| **블라인드** | 후순위(P1). 서로 다른 anon_id 기준 신고 **5건 이상**이면 매치업 blinded 처리. URL 직접 접근 시 안내 + noindex. |
| **매치업 생성** | MVP에서 제외(Next). MVP는 **시드 데이터**로 시작. |

## 4. 페이지/라우트 맵 (3페이지 기준)

| 라우트 | 목적 | 주요 구성 |
|--------|------|----------|
| `/` | 메인: 매치업 목록 | MatchupCard 리스트 |
| `/match/[id]` | 매치업 페이지: 투표 + 게시물 목록/작성 | MatchupDetail + Vote + PostList + PostForm |
| `/match/[id]/posts/[postId]` | 게시물 상세: 본문 + 댓글 | PostDetail + PostCommentList + PostCommentForm |

- 블라인드/삭제 안내 화면은 후순위(P1)이며, MVP 일정에 따라 생략 가능.

---

## 5. 상태/예외 처리(요약)

| 상황 | 처리 | 사용자 노출 |
|------|------|------------|
| anon_id 없음(첫 방문) | UUID 생성 후 localStorage+cookie 저장 | — |
| 이미 투표한 매치업 재투표 | DB unique로 차단 | “이미 투표했습니다” + 결과만 표시 |
| 게시물/댓글 검증 실패 | 서버 400 | “입력 길이를 확인해 주세요” |
| 게시물 댓글 쿨다운 미만 | 서버 429 | “잠시 후 다시 시도해 주세요” |
| 잘못된 id(postId 포함) | 404 | 404 또는 “찾을 수 없습니다” |

---

## 6. 입력 검증(권장)

| 항목 | 규칙 |
|------|------|
| 투표 | (anon_id, matchup_id) unique, item_id는 해당 matchup의 아이템만 허용 |
| 게시물 제목 | 5~80자, 공백만 불가 |
| 게시물 본문 | 20~2000자, 공백만 불가 |
| 댓글 본문 | 5~500자, 공백만 불가 |
| 닉네임 | 0~50자, 없으면 ‘익명’ 저장 |

---

## 7. MVP 범위 요약

- **포함**: 메인(매치업 목록), 매치업 페이지(투표+결과+게시물 목록/작성), 게시물 상세(댓글), SEO 최소, 반응형 최소, Supabase 테이블/정책 최소.
- **후순위(P1)**: 신고/블라인드(시간 부족 시 MVP에서 제외 가능).
- **제외(Next)**: 로그인/관리자/수익화/고급 정렬.

---

## 8. MVP 완료 정의(DoD) — 10개

- [ ] anon_id 생성/저장 및 모든 쓰기 요청에 포함된다.
- [ ] 메인에서 매치업 목록이 최신순으로 보이고 이동된다.
- [ ] 매치업 페이지에서 좌/우 항목이 정상 노출된다.
- [ ] 투표 1회 제한이 동작하고 결과가 표시된다.
- [ ] 매치업 페이지에서 게시물 목록이 보인다.
- [ ] 매치업 페이지에서 게시물 작성이 가능하고 목록에 반영된다.
- [ ] 게시물 상세에서 본문이 정상 노출된다.
- [ ] 게시물 상세에서 댓글 작성/목록이 정상 동작한다(쿨다운 포함).
- [ ] SEO 메타가 메인/매치업/게시물에 적용된다.
- [ ] 모바일/데스크톱에서 UI가 깨지지 않는다.
