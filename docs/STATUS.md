# 진행상태·QA — 픽콜(가칭) MVP

PRD_MVP 기준 QA 체크리스트·엣지케이스·완료 정의(DoD). 검증 가능한 문장으로 기술.

---

## 1. MVP 기능별 QA 체크리스트

### 익명 식별(anon_id)

- [ ] 최초 방문 시 UUID가 생성되어 localStorage와 cookie에 저장된다.
- [ ] 동일 브라우저에서 재방문 시 기존 anon_id가 유지된다.
- [ ] 투표·댓글·신고 요청 시 동일 anon_id가 전달된다.

### 홈(목록)

- [ ] 비블라인드 매치업만 최신순으로 카드 형태로 노출된다.
- [ ] 카드 클릭 시 해당 매치업 상세(/match/[id])로 이동한다.
- [ ] 블라인드된 매치업은 목록에 전혀 보이지 않는다.

### 매치업 상세·투표

- [ ] 좌/우 2개 항목(텍스트·이미지 URL)이 명확히 구분되어 표시된다.
- [ ] 동일 anon_id로 해당 매치업에 1회만 투표 가능하다(제출 후 변경 불가).
- [ ] 이미 투표한 경우 투표 버튼 비활성 또는 결과만 보인다.
- [ ] 투표 후 항목별 득표 수 또는 비율이 갱신되어 보인다.

### 댓글

- [ ] 5~500자만 등록 가능하다(5자 미만·500자 초과 시 오류 메시지).
- [ ] 닉네임 없이 등록 시 표시명이 '익명'이다.
- [ ] 동일 anon_id 기준 10초 쿨다운 후에만 재등록 가능하다(미만 시 안내 문구).
- [ ] 등록된 댓글이 최신순으로 목록에 보인다.

### 신고·블라인드

- [ ] 신고 시 사유 5종(SPAM, HATE, NSFW, ILLEGAL, OTHER) 중 선택 후 제출 가능하다.
- [ ] 동일 anon_id로 동일 매치업에 1회만 신고 가능하다.
- [ ] 서로 다른 anon_id로 신고 5건 이상 시 해당 매치업이 블라인드 처리된다.
- [ ] 블라인드된 매치업은 목록에 안 보인다.
- [ ] 블라인드된 매치업 URL 직접 접근 시 안내문 + noindex가 적용된다.

### 반응형·기타

- [ ] 모바일·데스크톱에서 레이아웃이 깨지지 않는다.
- [ ] 홈·상세 페이지에 고유 title/description이 설정되어 있다.
- [ ] 잘못된 match id 접근 시 404 또는 "찾을 수 없습니다"가 노출된다.

## 2. 엣지케이스 목록

| 구분 | 상황 | 기대 동작 |
|------|------|-----------|
| 투표 | 이미 투표한 매치업에 재투표 시도 | DB unique로 거부 또는 409; 화면에 "이미 투표했습니다" 등 표시, 버튼 비활성. |
| 댓글 | 5자 미만 또는 500자 초과 제출 | 서버 검증 실패, 400; "5~500자로 입력해 주세요" 표시. |
| 댓글 | 10초 미만 재등록 시도 | 서버/클라이언트에서 거부; "잠시 후 다시 시도해 주세요" 등. |
| 신고 | 동일 anon_id로 같은 매치업 재신고 | DB unique로 거부; 이미 신고했음 안내. |
| 블라인드 | 신고 5건 도달 직후 | 해당 매치업 blinded_at 설정, 목록에서 제외, URL 접근 시 안내+noindex. |
| 데이터 없음 | 존재하지 않는 matchup id | 404 페이지 또는 "찾을 수 없습니다". |
| anon_id | localStorage/cookie 삭제 후 재방문 | 새 anon_id 생성·저장; 기존 투표/댓글과는 별개로 취급. |

## 3. 완료 정의(DoD) — 10개

- [ ] **anon_id**: UUID 생성 후 localStorage + cookie 저장되고, 모든 참여 기능에서 동일 값이 전달된다.
- [ ] **목록/상세**: 시드 데이터 기준 매치업 목록(카드)과 상세(좌/우 항목)가 정상 노출된다.
- [ ] **투표**: 매치업당 anon_id 1회만 투표 가능하고, 제출 후 변경 불가·결과가 즉시 반영된다.
- [ ] **댓글**: 5~500자, 10초 쿨다운, 닉네임 없으면 '익명'으로 표시·저장된다.
- [ ] **신고**: SPAM/HATE/NSFW/ILLEGAL/OTHER 중 선택 제출 가능하고, 서로 다른 anon_id 5건 이상 시 블라인드 처리된다.
- [ ] **블라인드**: 블라인드된 매치업은 목록에 안 보이고, URL 직접 접근 시 안내문 + noindex가 적용된다.
- [ ] **검증**: 댓글 길이·쿨다운·투표 1회 제한이 서버(또는 DB 제약)에서 동작한다.
- [ ] **반응형**: 모바일·데스크톱에서 레이아웃이 깨지지 않는다.
- [ ] **SEO**: 홈·상세 페이지에 고유 title/description이 설정되어 있다.
- [ ] **DB·RLS**: Supabase 테이블(votes unique 포함)과 RLS 정책이 배포되어 읽기/쓰기가 의도대로 동작한다.
